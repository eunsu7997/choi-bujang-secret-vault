이 문서는 학생(유은수)이 작성한 기록입니다. **재현 기록은 학생 진술**이며, ALEPH 서버가 새 환경에서 실행해 확인했다는 뜻이 아닙니다. 22단계 통과는 원문 검토 기준의 수료이며 실제 운영 인증이나 v1.0 인증이 아닙니다.
실행 방법·구성도는 [STUDENT_RUNBOOK.md](STUDENT_RUNBOOK.md)를 따릅니다.

## 7. 누락·미해결 사항

- 19단계 실집행: 연동 시스템 집행기 연결과 같은 학생·프로젝트·대상의 실행 결과 확인은 **미완료**(운영 측 준비 대기). 학생 화면은 상태 구분까지만 구현.
- 실제 SDP 연결(본인·기기·업무 앱 판정·보안 기록): 기본 실행은 `disconnected`. 실제 연결 화면은 미확인.
- 실제 AI 연결 점검·사건 설명: 앱 권한 준비 여부에 따라 달라 이 기록에서 성공으로 적지 않음.
- OSV 실제 조회: 허용 목록 설정 전에는 not_configured·not_checked.
- 실행 도구 옵션 중 `-Port`는 이번 재현에서 확인, `-Background`·`-Demo`·`-NoNativeHost`는 미확인.
- macOS·Linux용 실행 절차 없음.
