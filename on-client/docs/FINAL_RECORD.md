# Halo 완성 기록 · 시연 순서 (마지막 총공세)

과정이 준 '완성 기록틀' 순서대로 적었습니다. **직접 확인한 것만** 결과로 적고, 확인하지 않은 것은 '미확인'으로 둡니다. 비밀번호·API 키·실명·연락처·개인 폴더 경로는 적지 않습니다.

## 1. 행사와 앱
- 행사명: 2026 KIT K-뉴딜 SKT ALEPH 공동 방어전
- 앱 이름: Halo (ZTNA·XDR 보안 Agent)
- 작전 선택: 화면 틀 **관제 대시보드형** · 포장 형태 **포장 없이 내 PC에서 실행**

## 2. 고른 핵심 기능 3개

### 핵심 기능 1 · 내 PC 상태 (Halo 요약 대시보드)
- 제공된 부분: 로컬 서버의 `GET /api/pc/status`(CPU·메모리·디스크·네트워크·방화벽·Windows 기록을 일반 권한으로 읽음), 제공 「내 PC 상태」 카드
- 내가 직접 개선한 부분(`student/extension.mjs`):
  - 6개 항목을 ● 정상 / ▲ 주의 / ? 확인 불가로 판정한 카드와 판정 기준
  - 측정 시각(KST), '값 종류: 이 PC 실측' 표시, 다음 할 일
  - 최근 기록 10회, CPU·메모리 변화 그래프(`<meter>`)
  - SDP 연결 상태를 PC 값과 분리한 한 줄
  - 키보드 초점 복귀
- 실제 확인 결과: 학생 Windows PC, 커밋 `2d8763b`, 2026-11-09 01:52 KST
  - 정상: CPU 56.7%, 메모리 67.4%, 디스크 여유 37%, 방화벽 Domain·Private·Public 모두 켜짐, 네트워크 IPv4 3개
  - ▲ 주의: Windows 이벤트(오류 1건, 경고 10건)
  - 근거 화면: `evidence/windows-dashboard-2d8763b.png`
- 실제 확인 결과(최신 화면): 학생 Windows PC, 커밋 `3e5772e`, 2026-11-09 02:07 KST
  - 'SDP 미연결 · 아래 내 PC 값과는 별개' 줄과 '값 종류: 이 PC 실측(local-pc)' 표시
  - 정상: CPU 64.8%, 메모리 62%, 디스크 여유 37%, 방화벽 3개 프로필 켜짐, 네트워크 IPv4 3개
  - ▲ 주의: Windows 이벤트(System·Application 오류 1건, 경고 10건, 최근 24시간)
  - 이벤트 건수가 침해·공격 탐지 결과가 아니라는 안내 표시
  - 2번 확인한 변화 그래프: CPU 42.3% → 64.8%(+22.5%p), 메모리 62.1% → 62%(-0.1%p)
  - 근거 화면: `evidence/windows-dashboard-3e5772e.png`
- 잘못된 입력·연결 실패 때의 동작(가짜 DOM 시험으로 확인):
  - 조회 실패 시: 오류 이유와 code를 표시하고, 직전 결과는 '이전 결과입니다'로 표시
  - schema가 다를 때: 6개 모두 확인 불가
  - 권한이 없을 때: '확인 불가(권한 없음)'로 두고 관리자 실행을 권하지 않음
- 근거: `docs/STUDENT_RUNBOOK.md` 10장, `docs/RELEASE_RECORD.md` 8장

### 핵심 기능 2 · 기록 보기 (보안 기록·확인 기록)
- 제공된 부분: 보안 기록 조회(`/api/events`, 최근 40건)와 제공 목록 화면
- 내가 직접 개선한 부분:
  - 15단계 `renderEvents`: 최신순 목록, '기록 종류'·'업무 앱'·'접속 상태' 필터, 근거·규칙·세 상태 상세 보기
  - 대시보드의 최근 확인 기록
- 실제 확인 결과: 화면 동작은 확인했습니다. 실제 SDP 기록은 **SDP 미연결**이라 미확인입니다(화면에는 `ENGINE_NOT_CONNECTED`로 표시).
- 잘못된 입력·연결 실패 때의 동작: 빈 배열이면 '표시할 기록이 없습니다', 조회 실패와 `CONTRACT_MISMATCH`는 구분해서 표시하고 이전 목록을 지웁니다(가짜 DOM 시험).
- 근거: 15단계 통과 기록, `docs/RELEASE_RECORD.md` 4장

### 핵심 기능 3 · 위험 알림
- 제공된 부분: 알림 모음(notifications), 패키지 조회(`/api/vulnerabilities`)
- 내가 직접 개선한 부분:
  - 대시보드의 ▲ 주의와 다음 할 일
  - 16단계 알림 목록(자료·code·message)
  - 20단계 OSV 결과 표시: 미조회를 '취약점 없음'으로 보지 않음
- 실제 확인 결과: Windows 이벤트 ▲ 주의와 다음 할 일 표시는 확인했습니다(커밋 `2d8763b`). OSV 실조회는 허용 목록 미설정이라 `not_configured`·`not_checked`로, 미확인입니다.
- 잘못된 입력·연결 실패 때의 동작: 연결 실패 알림을 자료별로 표시하고, 알림이 없으면 '주의할 알림이 없습니다'로 표시합니다.
- 근거: 16·20단계 통과 기록, 앱 화면의 알림 목록

## 4. 같은 최종 소스로 다시 실행한 기록
- 실행 환경: Windows · PowerShell · Node.js v24.20.0 (수업 기준 v24.19.0)
- 필요한 것: Git, Node.js 22~24. 외부 npm 의존성은 없음
- 최종 소스 커밋: 이 문서를 포함한 커밋입니다. `git rev-parse HEAD`로 확인한 값과 GitHub `main`이 같아야 합니다. 마무리 제출에도 그 값을 씁니다.
- 실행 패키지 경로: 해당 없음(포장하지 않음)
- 다시 실행한 명령:
  ```powershell
  cd $HOME\Documents\choi-bujang-secret-vault\on-client
  powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5190
  ```
  → 브라우저에서 `http://127.0.0.1:5190/` → 보호 현황 → 「내 PC 다시 확인」
- 다시 실행한 시각과 결과:
  - 2026-11-09 01:52 KST, Windows, 커밋 `2d8763b`: 앱 이름 Halo, 대시보드 6개 카드가 실제 값으로 표시됨

  - 2026-11-09 02:07 KST, Windows, 커밋 `3e5772e`: 앱을 끄고 다시 켠 뒤 「내 PC 다시 확인」을 2번 누름 → SDP 미연결 줄, 실측 표시, 이벤트 안내, 변화 그래프 표시 확인

## 시연 순서 (약 3분)
1. PowerShell에서 위 명령으로 실행 → `http://127.0.0.1:5190/` 접속. 앱 이름 **Halo**, 파란 테마를 확인합니다.
2. 맨 위 빨간 안내와 'SDP 미연결' 줄을 보여 줍니다. "회사 보안 서버는 연결하지 않았고, 아래 PC 값과 섞지 않는다"고 설명합니다.
3. **내 PC 상태**: 「내 PC 다시 확인」(Tab·Enter로도 가능) → 6개 카드, 측정 시각, '이 PC 실측' 표시. 한 번 더 눌러 변화 그래프와 처음 대비 변화를 보여 줍니다.
4. **위험 알림**: ▲ 주의 카드와 다음 할 일을 보여 줍니다. "이벤트 건수는 침해 탐지 결과가 아니다"라는 안내도 짚습니다.
5. **기록 보기**: 최근 확인 기록을 펼치고, 보안 기록 메뉴의 필터와 상세 화면(SDP 미연결로 빈 상태·오류 구분)을 보여 줍니다.
6. 한계: 8장의 미연결·미확인 항목을 말하고 마칩니다. 근거는 커밋 번호, `RELEASE_RECORD.md`, 이 문서입니다.
